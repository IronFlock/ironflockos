## New

- An OS update now also renews the boot script on the IRONFLOCKOS partition, which until now stayed as the device was installed. After the update to this release has proven itself (the device-agent reached IronFlock), the device takes the new boot script at its next restart, as a trial: if that start does not succeed, the device starts with the boot script it had, and tries the same version once more before it gives it up. Devices installed with 0.11.0 to 0.16.0 thereby get what 0.17.0 brought to new installations: IronFlock's logo while they start, the usual keys at the screen, and the repair of the data partition at start.
- The first images for NVIDIA Jetson Orin (`jetson-orin`, Jetson Linux 39.2.1 on Ubuntu 24.04): a slot image, its update bundle, and a flash kit that flashes an Orin Nano or AGX Orin developer kit from a Linux PC. The Jetson images are not yet proven on hardware: no Jetson module has started them yet. They contain NVIDIA's software under the NVIDIA Driver License Agreement: https://instance-registry.ironflock.com/dl/ironflockos/0.19.0/NVIDIA-LICENSE.txt
- Every image carries IronFlock GmbH's written offer of the source code of its GPL and LGPL programs, at the end of `/usr/share/doc/ironflockos/copyright`.

## Changed

- `ironflock` 2.4.0 is in the image.
- The login prompt names IronFlockOS and its version instead of the distribution it is built on.
