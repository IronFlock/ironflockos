## Fixed

- The Jetson Orin flash kit now activates ARM64 emulation when Ubuntu has installed QEMU but cannot run ARM64 programs. Flash package preparation previously stopped with an `Exec format error` on affected hosts.

The Jetson image is not yet proven on hardware. Its NVIDIA components are distributed under the [NVIDIA Driver License Agreement](https://instance-registry.ironflock.com/dl/ironflockos/0.19.2/NVIDIA-LICENSE.txt).

## Changed

- IronFlockOS images now include the `ironflock` CLI 2.7.0, up from 2.4.0.
