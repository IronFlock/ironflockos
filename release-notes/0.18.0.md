## Security

- Docker Buildx 0.39.0 closes a flaw in the HTTP/2 library it is built with, where a peer could keep it busy with a flood of settings frames (CVE-2026-78669). containerd.io 2.4.2-4 is containerd 2.4.2 rebuilt with Go 1.27.4 and runc 1.5.3.

## New

- `ironflock` 2.2.0 is in the image.
- `/usr/lib/ironflockos/screen-report`, run as root, prints what the last start showed on the screen: the times from the firmware to the first app, the graphics mode, whether the screen shows the splash where it belongs, the input devices with the touch screen, and the settings behind the keys. It changes nothing on the device; `--screenshot FILE` also writes a picture of the screen.

## Changed

- Docker Engine 29.10.0 and Docker Compose 5.7.1. With this Docker release, a device whose Docker settings name insecure registries treats a registry on the device itself (`localhost`, `127.0.0.1`) as insecure only when it is in that list. The device-agent lists the registry of an appliance on the device by itself; a registry you added by hand at a `localhost` address needs its own entry.
