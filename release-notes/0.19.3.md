## Changed

- IronFlockOS images include IronFlock CLI 2.7.1. On a supported Ubuntu host, its USB flash wizard guides users through installing IronFlockOS on a Jetson Orin.

- The signed release catalog now includes the size and SHA-256 of the Jetson Orin flash kit. CLI versions with the USB flashing wizard can verify the kit before running it on the host.

The Jetson image is not yet proven on hardware. Its NVIDIA components are distributed under the [NVIDIA Driver License Agreement](https://instance-registry.ironflock.com/dl/ironflockos/0.19.3/NVIDIA-LICENSE.txt).
